### 💫 About me

I build **AI agents** and the backends they run on — mostly Python and TypeScript,
with Flutter when it needs to be an app. I like problems where the data doesn't
arrive in a tidy API and you have to go get it yourself.

- 🌱 Currently building **AI agents** and automation pipelines
- 🧠 Into LLM fine-tuning, retrieval, and data engineering at scale (Hadoop · Spark · Kafka)
- 🎓 CS graduate of **ESI-SBA** — *École Supérieure en Informatique, Sidi Bel Abbès*
