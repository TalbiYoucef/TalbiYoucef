### 🛠️ Things I've worked on

- **Probabilistic OLAP** (Master's thesis): a Python engine that places imprecise records into the right cells of an OLAP cube, with 8 interchangeable methods from EM to XGBoost and neural networks. ERA5 climate data goes into a SQL Server star schema with Power BI dashboards on top, and all 8 methods were benchmarked on TPC-DS and ERA5.
- **AdForge** (freelance, 2025 – 2026): an AI SaaS that turns a product page into ready-to-post video and image ads for TikTok, Meta and YouTube.
- **[PetraQ](https://github.com/partzel/petraq)** (team project): turned ~2M rows of oil well records into Q&A pairs, fine-tuned Qwen2.5-1.5B and Llama 3.2, compared them in a RAG setup with FAISS, and ended with a Mistral chatbot that writes pandas code to answer questions about the data.
- **Reddit to Reels** (freelance, 2025): a FastAPI service orchestrated with n8n that turns Reddit posts into Instagram Reels and publishes them automatically.
- **GPS & IoT truck tracking** (2023, with a partner): Arduino sensors, cargo alerts, an admin dashboard and a driver mobile app.
